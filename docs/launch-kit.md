## Short English post

I built an open-source Codex Skill for trips that survive real changes: booking states with evidence, protected appointments, route-linked meals, day-of cards, and a clear first cut when a day goes wrong.

The repo contains a redacted France historical case study and a separate fictional dataset you can regenerate offline with one command into a route atlas, daily cards, phone page, calendar, and disruption advice. The France case is not live ticketing advice or a runnable copy of the fictional dataset.

[Repository](https://github.com/judefluen-coder/plan-and-maintain-trips) · [France case](https://github.com/judefluen-coder/plan-and-maintain-trips/tree/main/examples/france-2026) · [Runnable demo](https://github.com/judefluen-coder/plan-and-maintain-trips/tree/main/examples/lisbon-coast)
