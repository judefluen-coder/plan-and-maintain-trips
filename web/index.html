    CONNECT YOUR TRIP

    把自己的旅程带进工作台

    先让已安装 Skill 的代理生成 trip.json。最通用的同机方式是启动共享文件工作台：代理保存同一文件后，地图和日程自动刷新；网页不会调用模型。

    01代理生成并校验 trip.json
    02运行共享文件模式，打开打印的专属链接
    03在工作台复制修改要求，交给代理处理
    python3 bridge/server.py --provider manual --trip /你的路径/trip.json

    Codex CLI 或 Claude Code CLI 也可改用 --provider codex 或 --provider claude，从网页直接生成待确认提案；这会使用所选代理自己的模型配额。跨设备则使用「导入行程」及 JSON 下载/重新导入。

    浏览器可能询问是否允许连接本机服务；只对你信任的页面授权，不要分享专属链接。
